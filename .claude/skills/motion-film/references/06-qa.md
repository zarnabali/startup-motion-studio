# Checks, critique loop & delivery

## 1. Automated checks — before EVERY owner gate (studio-prompt.md `<checks>`)
```bash
PY tools/check_film.py projects/<job>/film/out/full/film.mp4 --film projects/<job>/film
#  -> out/full/checks/CHECKS.md (format · duration · loudness/true peak · blank frames · white flashes · frozen runs)
#  -> frame_sheet.jpg (1 fps) · phone_sheet.jpg (360 px wide = phone) · contact.jpg (2 fps)   ← Claude LOOKS at all three
cd projects/<job>/film
PY render.py qa out/qa --from-draft          # one frame per second (ref | ours when remaking), no new render
PY render.py pops out/full/film_silent.mp4   # unexplained one-frame jumps
```
Report every check as **pass / fixed / n/a** (fixed and n/a need a note). Manual checks the critic must sign:
spelling-and-facts · text-safe-area (5 % inside each edge) · no-collisions · text contrast 4.5:1 at the worst frame ·
sync (each key VO word within 2 frames of its visual) · every cut has a carrier · nothing frozen > 1 s · no blank/dip frames.

## 2. Critics (separate read-only agents, DEFAULT REJECT; judge ≠ builder)
Brief: `film/CRITIC_BRIEF.md` (this section + LOOK.md + SPEC.md). Give them the phone_sheet first.
- **Motion critic**: springs (no linear moves, no cartoon bounce), stagger 2–4 f, overlap, carriers on every cut, dead
  frames, whips at peak velocity, drop on the key visual, sync to beats.json.
- **Design critic**: fidelity to the reference layout (remakes), UI fidelity to the owner's screenshots, headlines
  ≥ 5 % of frame height and readable at 360 px, one accent, banned defaults, AI-looking photos (must pass as real),
  copy truth (no invented prices/dates/metrics; demo data labelled).
Each scores every shot /10 on: hook (first 2 s) · readability at 360 px · motion quality · variety (new thing every
2–4 s) · composition · brand/data accuracy · sound sync. Defects come with frame numbers + a measurable fix.
**Fix only shots ≤ 7, don't touch 9+; at least 3 rounds or until every shot is ≥ 8.** Re-render only the touched
cut-to-cut segments (`full --pipe` + `concat`).

## 3. Owner notes protocol (studio-prompt.md `<notes>`)
Answer EVERY note in the next version and say exactly what changed ("Cards now 2:3, nothing cropped"), never
"addressed". Sort each note into **error** (a check should have caught it) or **taste**. Fix both. For every error
no check caught → write a new check below and a line in `brand/LEARNINGS.md`; run it on every future film. Notes
that apply to all future work also go into BRAND_BRAIN §8.

### Checks born from owner notes (starter set — add yours)
- Images in cards/tiles must not be cropped: container aspect == image aspect (or object-fit: contain).
- No AI-looking photos: every photo plate made with `make_image.py --real` and inspected at 100 %.
- Logo used exactly as given; never combined with another mark.
- No reference narration in any audio track; brand VO only.
- Text that says itself on screen gets no VO (questions, labels) — VO only adds meaning.
- No black/blank frames at shot boundaries (check_film "blank frames" = 0).
