# Caption and hook patterns (fill with the brand's facts — never invent)

## Hooks (first line / first 1.5 s)
- Situation: "Monday, 8:40, nothing to wear for the 9:00 pitch."
- Before → after: "From 40 tabs to one answer in 6 seconds."
- Sharp question the audience actually asks: "Why does every invoice tool need 12 clicks?"
- Surprising, sourced fact: "<sourced number> of <audience> still do <X> by hand."
- Build-in-public: "We almost shipped this feature wrong. Here's what changed."
Avoid: "Introducing…", "We're excited to announce…", "Game-changer", "Revolutionary", emoji walls, ALL CAPS.

## Body
1-3 short lines of value (what the viewer gets), in the brand's voice words. One feature per post: input → what the
product does → output. Then ONE CTA line from BRAND_BRAIN §6 with the URL.

## Templates
LinkedIn (plain, first person):
```
<hook>

<2-3 lines: the problem, what we built, what it changes for <audience>>

<CTA> → <url>

#<broad> #<niche> #<brand>
```
Instagram / TikTok (casual, short lines):
```
<hook> 👀
<one-line payoff>
<CTA> — link in bio
#<niche> #<niche> #<broad> #<brand> ...
```
X:
```
<hook that is also the payoff> <url>
```

## Hashtag mix
1-2 broad (#startup #ai), 2-4 niche (the audience's own tags), 1 brand tag. Check each tag's recent posts are on-topic
before using it. Never use tags of competitors or unrelated trends.

## Alt text
What is visible, in one sentence, including on-screen text. "Phone screen: the app turns a photo of a receipt into a
categorised expense in 2 seconds."
