# Brand fonts

Put your licensed font files here (.woff2 / .otf / .ttf) and list them in `brand/tokens.json` → `fonts`.
`new_film.py` copies them into every film. Keep files small (subset them if a file is > 500 KB: big fonts slow or
crash the renderer). Free default: Inter (SIL OFL) — https://rsms.me/inter/ — download `Inter-Regular.woff2` and
`Inter-Medium.woff2` here, or change the list.
