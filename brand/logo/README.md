# Logo

Put your logo here as clean vector files with a transparent background:
- `wordmark.svg` — the full logo (name). Used by `CORE.wordmark(width, fill)`.
- `mark.svg` — the square symbol / app icon. Used by `CORE.mark(size, fill)`.
Only PNG? Ask Claude to trace it to SVG and check the edges at 400 % zoom. Never redraw or "improve" a logo.
